# Hadoop Word Count Using MapReduce

## Introduction

This experiment demonstrates the implementation of the Word Count application using the Hadoop MapReduce framework.

The experiment involves creating an input text file, uploading it to HDFS, executing the built-in Hadoop Word Count MapReduce program, and viewing the generated word frequency results.

## Objective

The objectives of this experiment are:

- Create a text file containing sample data.
- Upload the input file to HDFS.
- Execute the Hadoop MapReduce Word Count program.
- Generate the frequency of each word.
- View the generated results from HDFS.

## Technologies Used

- Apache Hadoop
- HDFS
- YARN
- MapReduce
- Java
- Ubuntu / WSL

## Workflow

1. Create the input text file.
2. Verify the contents of the input file.
3. Start Hadoop services.
4. Create an HDFS input directory.
5. Upload the input file to HDFS.
6. Execute the Hadoop Word Count program.
7. Check the output directory.
8. Display the word frequency results.
9. Stop Hadoop services.
