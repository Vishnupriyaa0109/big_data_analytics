# Spark Exercises

This repository contains Apache Spark exercises and Big Data projects developed as part of the Big Data Analytics laboratory.

The exercises demonstrate fundamental and advanced concepts of Apache Spark, while the projects showcase practical implementations of real-time data processing and optimization techniques.

## Technologies Used

- Apache Spark 4.1.2
- PySpark
- Apache Kafka
- Apache Cassandra
- Hadoop HDFS
- Hadoop Streaming
- Python 3
- Java (JDK)
- WSL (Ubuntu)
- Spark Structured Streaming
