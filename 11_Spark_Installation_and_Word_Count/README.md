# Apache Spark Installation and Word Count

## Project Title

Apache Spark Installation, Configuration, and Word Count using PySpark DataFrames.

## Overview

This project demonstrates the installation, configuration, and verification of Apache Spark on Ubuntu/Linux.

It also includes the implementation of the classic Word Count application using PySpark DataFrames.

The project is divided into two phases:

- Phase 1: Apache Spark Installation and Configuration
- Phase 2: Word Count using PySpark DataFrames

## Objectives

### Phase 1

- Install OpenJDK 21.
- Install Apache Spark.
- Configure environment variables.
- Verify Spark installation.
- Launch Spark Shell.
- Launch PySpark.

### Phase 2

- Understand PySpark.
- Create distributed datasets.
- Work with DataFrames.
- Perform Word Count.
- Read text files using Spark.
- Understand Spark transformations and actions.

## Software Requirements

- Ubuntu Linux 22.04 or later.
- OpenJDK 21.
- Apache Spark 4.1.x.
- Hadoop 3.x.
- Python 3.x.

## Phase 1 - Apache Spark Installation

The following activities are performed:

- Update Ubuntu packages.
- Install OpenJDK 21.
- Configure JAVA_HOME.
- Download Apache Spark.
- Extract Spark binaries.
- Move Spark to the installation directory.
- Configure SPARK_HOME and PATH.
- Verify Spark installation.
- Launch Spark Shell.
- Launch PySpark.
- Check the installed Spark version.

## Phase 2 - PySpark Word Count

The Word Count exercise demonstrates:

- Starting PySpark.
- Creating a distributed dataset.
- Converting an RDD into a DataFrame.
- Splitting sentences into words.
- Counting word frequency.
- Sorting the results.
- Displaying the final output.
- Reading text from an external file.
- Performing Word Count on the text file.

## Concepts Covered

- Apache Spark.
- Spark Architecture.
- SparkSession.
- Resilient Distributed Dataset (RDD).
- DataFrames.
- Distributed Computing.
- Spark SQL.
- Transformations.
- Actions.
- Lazy Evaluation.
- Word Count.
- Text Processing.

## Learning Outcomes

After completing this project, the following concepts are understood:

- Installing and configuring Apache Spark on Ubuntu Linux.
- Understanding the Apache Spark environment.
- Launching Spark Shell and PySpark.
- Creating distributed datasets.
- Working with Spark DataFrames.
- Performing text processing using PySpark.
- Implementing the Word Count application.
- Reading and processing external text files.
- Understanding Spark transformations and actions.
- Understanding distributed data processing.

## Conclusion

The project demonstrates Apache Spark installation and configuration along with its verification using Spark Shell and PySpark.

It also implements the classic Word Count application using PySpark DataFrames.

This provides practical experience with distributed computing, DataFrame operations, and text analytics.
