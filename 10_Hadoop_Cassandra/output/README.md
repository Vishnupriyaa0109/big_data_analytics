# Output

This folder contains the output generated by the Hadoop MapReduce jobs.

## Files

### daily_aggregates.txt

Contains the daily listening activity calculated from the batch music streaming dataset.

The output includes:

- Date
- Total number of plays
- Total listening duration

### top_songs.txt

Contains the songs ranked according to their number of plays.

The output includes:

- Song name
- Number of plays

## Purpose

These output files represent the results produced by Hadoop MapReduce processing.

The results can be loaded into Cassandra for further querying and analysis.
